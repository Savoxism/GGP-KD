\section{GGPKD: Global Geometry through Local Alignment}
\label{sec:method}

GGPKD distills an embedding teacher into a smaller student on neighborhoods
retrieved once by the frozen base student. The student selects each row's
columns, while the teacher supplies the cosine targets over those columns. The
method exposes graph width \texttt{graph\_k}, relational coefficients
\texttt{r0\_weight}/\texttt{r1\_weight}, and auxiliary-row weight
\texttt{row\_weight}. These three loss coefficients are independent and applied
directly, without normalization. All temperatures and targets are
derived from the cached embeddings. The graph and teacher embeddings are cached before training and are not needed at
inference.

\subsection{Student-selected, teacher-valued graph}
\label{sec:graph}

Let $\mathcal D=\{x_i\}_{i=1}^{N}$ be the deduplicated training corpus. The
teacher and frozen base student each encode every text once, and their embeddings
are $\ell_2$-normalized. For each node $i$, we retrieve the
$k=\texttt{graph\_k}$ most similar non-self nodes under the base student,
forming $\mathcal N_i^S$. If $s_i^{T,(q)}$ is the teacher's $q$-th largest
corpus cosine, the row bandwidth is
\begin{equation}
\tau_i=\frac{s_i^{T,(1)}-s_i^{T,(k)}}{\log k}.
\label{eq:row-bandwidth}
\end{equation}
On the teacher's own reference top-$k$, the $k$-th neighbor receives $1/k$ of
the nearest neighbor's unnormalized weight. The target below is evaluated on
the student-selected set and need not have that same endpoint ratio. Because
the bandwidth scales with any affine
rescaling of the similarities, the resulting softmax row is affine-invariant
and requires no teacher-specific temperature tuning.

The neighbor set is the student's retrieved list itself,
$\mathcal N_i^S=\mathrm{top}\text{-}k_S(i)$, and every node has degree exactly
$k$. Teacher-kNN is retained as a source ablation. A mutual
filter, which keeps $i\rightarrow j$ only when the two nodes retrieve each
other, suppresses hubs but discards directed relations; we report it as
an ablation in Section~\ref{sec:experiments}. The teacher transition row is
\begin{equation}
P_i^T(j)
=\frac{\mathbf 1[j\in\mathcal N_i^S]\exp(c_{ij}^T/\tau_i)}
{\sum_{u\in\mathcal N_i^S}\exp(c_{iu}^T/\tau_i)}.
\label{eq:teacher-transition}
\end{equation}
The bandwidth in Equation~\eqref{eq:row-bandwidth} is read from a teacher
reference list of the same fixed width for every node; the target values are
teacher cosines evaluated on the student-selected columns.

\subsection{Deterministic candidate pool}
\label{sec:candidates}

The candidate set for anchor $i$ is exactly $\mathcal N_i^S$.
Every column the base student retrieved is supervised and none is discarded, so no
truncation constant enters the objective and every anchor is scored on the same
number of columns, $k$. GGPKD draws no hard or random negatives and performs no
per-epoch sampling: the candidates are a deterministic function of the graph and
remain fixed throughout training. Within a mini-batch $B$, candidates are
deduplicated into the shared pool
\begin{equation}
\mathcal P_B=\bigcup_{i\in B}\mathcal N_i^S,
\label{eq:shared-pool}
\end{equation}
so each distinct candidate text is encoded once.

\subsection{Training objective}
\label{sec:objective}

The graph-scale loss matches each teacher row with a student softmax over the
same columns and at the same stored bandwidth:
\begin{equation}
\mathcal L_{r=1}
=\frac{1}{|B|}\sum_{i\in B}
D_{\mathrm{KL}}\!\left(
P_i^T
\,\middle\|\,
\operatorname{softmax}_{j\in\mathcal N_i^S}(c_{ij}^S/\tau_i)
\right).
\label{eq:graph-loss}
\end{equation}

This local row ranks candidates within an anchor's own neighborhood. To also
calibrate similarities across the batch, the ambient loss uses the complete
shared pool. Its temperature is derived from the graph as
$\tau_0=\operatorname{median}_i\tau_i$ and is shared by teacher and student:
\begin{equation}
\mathcal L_{r=0}
=\frac{1}{|B|}\sum_{i\in B}
D_{\mathrm{KL}}\!\left(
\operatorname{softmax}_{j\in\mathcal P_B\setminus\{i\}}(c_{ij}^T/\tau_0)
\,\middle\|\,
\operatorname{softmax}_{j\in\mathcal P_B\setminus\{i\}}(c_{ij}^S/\tau_0)
\right).
\label{eq:ambient-loss}
\end{equation}
The ambient and graph groups receive explicit, independent non-negative
coefficients $\lambda_0$ and $\lambda_1$, applied directly.

GGPKD also reuses non-anchor candidates as auxiliary row centers. Let
$\mathcal J_B=\mathcal P_B\setminus B$ and expose the portion of row $j$ that is
already present in the shared pool:
\begin{equation}
\Omega_j^B=\mathcal N_j^S\cap\mathcal P_B,
\qquad
\mathcal J_B^+=\{j\in\mathcal J_B:|\Omega_j^B|\geq2\}.
\end{equation}
Batch anchors are excluded because $\mathcal L_{r=1}$ already supervises their
transition rows. The remaining rows are matched uniformly at their stored
bandwidths:
\begin{equation}
\mathcal L_{\mathrm{row}}
=\frac{1}{|\mathcal J_B^+|}\sum_{j\in\mathcal J_B^+}
D_{\mathrm{KL}}\!\left(
P_j^T\big|_{\Omega_j^B}
\,\middle\|\,
\operatorname{softmax}_{u\in\Omega_j^B}(c_{ju}^S/\tau_j)
\right),
\label{eq:row-loss}
\end{equation}
where the restricted teacher row is renormalized on $\Omega_j^B$. This term
requires no additional student encoding because all centers and columns are
already in $\mathcal P_B$.

The complete objective is
\begin{equation}
\mathcal L_{\mathrm{GGPKD}}
=\underbrace{\lambda_0\mathcal L_{r=0}+\lambda_1\mathcal L_{r=1}}_{\mathcal L_{\mathrm{rel}}}
+\lambda_{\mathrm{row}}\mathcal L_{\mathrm{row}}.
\label{eq:full-objective}
\end{equation}
The defaults are $\lambda_0=\lambda_1=0.5$,
$\texttt{graph\_k}=200$, and
$\lambda_{\mathrm{row}}=\texttt{row\_weight}=1$. No coefficient is divided by
the sum of the others: common rescaling of $\lambda_0$ and $\lambda_1$ changes
their total strength relative to $\lambda_{\mathrm{row}}$. Increasing
\texttt{graph\_k} changes both neighborhood width and the bandwidth in
Equation~\eqref{eq:row-bandwidth}; those effects cannot be separated by a
single-axis sweep.

\paragraph{Cost.}
Exact graph construction requires $O(N^2d)$ similarity work, although an
approximate nearest-neighbor backend can replace the all-pairs search. During
training, the dominant cost is encoding the deduplicated shared pool;
$\mathcal L_{\mathrm{row}}$ reuses those embeddings. At deployment, inference
uses only the student encoder.
